# Bundled assets

- `fonts/Inter-Regular.ttf` — Inter by Rasmus Andersson, SIL Open Font License 1.1
  (`fonts/OFL-Inter.txt`). The fallback UI face; the app reads the operating system's own UI
  font (SF Pro on macOS) at runtime and never bundles it.
- `icon_1024.png` — generated by `scripts/generate_icon.swift`.
